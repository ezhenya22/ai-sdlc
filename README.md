# AI-SDLC: a lifecycle, the skills that power it, and one app built with it

**AI drafts, code checks, people decide.**

This repository holds an AI-assisted software development lifecycle and an example app taken through it, from
definition to prototype to MVP 1: associates request, approve and book business travel, which today runs on email
and spreadsheets.

Work in progress. The full write-up will live at **https://eugenetarasov.com/ai-sdlc**.

| Folder | What's in it |
|---|---|
| `sdlc/` | The lifecycle: stages, gates, ids, model choice, metrics |
| `.claude/skills/` | The skills, runnable in Claude Code |
| `docs/travel/` | The app's brief, PRD, stories, decisions (ADRs), reviews and run reports |
| `policy/` | Travel-policy rules as code, each with its public source |
| `app/`, `supabase/` | MVP 1 |
| `site/` | The website that presents all of the above |
